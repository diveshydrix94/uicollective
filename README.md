# uiCollectiveFigmaCode

React component library for **TheCollectiveKit** design system — the **single
source of truth** for UI components — wired to Figma with
[Figma Code Connect](https://www.figma.com/developers/code-connect).

When a designer or developer opens a component in Figma Dev Mode, they see this
repo's real code — props and all — instead of autogenerated CSS.

Components are **standalone** (they do not wrap MUI/Antd) but are held to the same
bar: **WCAG 2.1 AA accessible**, fully typed, composable, token-styled.

## Architecture — Atomic Design

```
src/
  atoms/        # indivisible primitives (native element + tokens). e.g. Button
  molecules/    # composed ONLY from atoms — no scratch primitives
  organisms/    # composed from molecules + atoms
  index.ts      # public entry — re-exports all layers
```

Consumers import from the package root:

```ts
import { Button } from 'ui-collective-figma-code';
```

Dependencies point one way only: `atoms ← molecules ← organisms`.

## Add a component — `/figma-connect`

This repo ships a Claude Code **skill + slash command** (`.claude/`) that automates
the whole flow: read the Figma node → classify (atom/molecule/organism) → generate
an accessible, atomic component with an MUI/Antd-grade API → map it → publish Code
Connect → verify.

```
/figma-connect <figma-node-url> <atom|molecule|organism> [ComponentName]
```

Example:

```
/figma-connect https://www.figma.com/design/…?node-id=12-34 molecule SearchBox
```

The command enforces: strict atomic composition (molecules use atoms only),
accessibility as a hard gate, token styling, and reuse-first. See
[.claude/skills/figma-connect/SKILL.md](.claude/skills/figma-connect/SKILL.md) and
its `references/` for the full governance.

### Prerequisite: Figma token
Put a Figma personal access token with **Code Connect write** scope in `.env`
(never commit it — `.env` is gitignored):

```
FIGMA_ACCESS_TOKEN=your_token_here
```

The command loads it automatically when publishing.

## Manual Code Connect commands

```bash
npm install

npm run typecheck        # tsc --noEmit
npm run cc:parse         # validate mappings (offline, no token)

# publish (needs the token from .env)
set -a; . ./.env; set +a
npm run cc:publish
# overwrite an existing UI-created mapping:
npm run cc:publish -- --force
# remove CLI-published mappings:
npm run cc:unpublish
```

After publishing, open the component in Figma Dev Mode → the **Code** panel shows
the `<Component />` snippet from this repo.
