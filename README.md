# uiCollectiveFigmaCode

React components from **TheCollectiveKit** design system, wired to Figma with
[Figma Code Connect](https://www.figma.com/developers/code-connect).

When a designer or developer opens the Button in Figma's Dev Mode, they see this
repo's real `<Button />` code — props and all — instead of autogenerated CSS.

## Components

| Component | Figma node | Code | Mapping |
|---|---|---|---|
| Button | [`1:397`](https://www.figma.com/design/Xs3B8FrGigk4A5zG9FtSMz/TheCollectiveKit_V.1.13?node-id=1-397) | [`src/Button.tsx`](src/Button.tsx) | [`src/Button.figma.tsx`](src/Button.figma.tsx) |

### Button prop mapping

| Figma property | Code prop |
|---|---|
| Label (text) | `children` |
| Type | `variant` — default \| subtle \| outline \| transparent |
| State | `status` — default \| success \| error \| warning \| information \| secondary |
| Size | `size` — default \| md \| lg |
| Status = disabled | `disabled` |
| Icon left + ↘Icon left | `iconLeft` |
| Icon right + ↘ Icon right | `iconRight` |

## Setup

```bash
npm install
```

## Publish Code Connect to Figma

Code Connect writes to your Figma file, so it needs a **Figma access token** with
the **Code Connect write** scope (Figma → Settings → Security → Personal access
tokens). This must be run by a person with edit access to the file — it is not
something an assistant can do for you.

```bash
# One-time: export your token (or put it in a .env file — never commit it)
export FIGMA_ACCESS_TOKEN=your_token_here

# Validate the mapping compiles and matches the Figma component
npm run cc:parse

# Publish the mapping to Figma
npm run cc:publish
```

After publishing, open the Button in Figma Dev Mode → the **Code** panel shows the
`<Button />` snippet from this repo.

To remove a published mapping:

```bash
npm run cc:unpublish
```
